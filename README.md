# Epoxy Flooring Avondale AZ

Static website deployed on Cloudflare Workers (static assets from `public/`, configured in `wrangler.jsonc`). Every push to `main` redeploys.

## Pages
- `/` home page
- Nine service pages, each at its SEO slug (for example `/garage-floor-coatings-avondale-az/`)
- `404.html`, `sitemap.xml`, `robots.txt`

## Editing
Pages are generated by `tools/build.py`:
- Phone, email and domain: `BUSINESS` at the top of `tools/build.py`
- Service page copy and SEO fields: `tools/content.json`
- Home page body: `tools/home-main.html`
- Shared styles and scripts: `public/assets/site.css`, `public/assets/site.js`

After editing, run `python3 tools/build.py` and commit the updated `public/` folder.
